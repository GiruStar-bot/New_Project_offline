# Frontier Council — 国家世界と生活・現物経済 / v0.3.1

Godot製の2D・シングルプレイヤーゲームです。現在は**地図・人物移動・土地交換と、生活・生産・現物税・手動の陸上輸送**を遊べる試作です。地図上にマス目はなく、24人が連続した座標で移動します。住民の仕事を割り当て、個人と国庫の在庫を分けて国家運営を試せます。外部AI、APIキー、追加プラグインは不要です。

最終目標は、国家が存続する限り進むサンドボックスです。軍事・外交・資源・経済圏・国際組織による運営、人材の登用・雇用・育成と業務の自動化を段階的に追加します。**その最終像のすべてを、この試作で実装したわけではありません。** 自国滅亡による終了は戦争・統治の段階で定義・実装します。新しい世界にはCitadel占領による終了はありません。

## 起動

1. Godot **4.5.1 Standard**で、このフォルダの `project.godot` をインポートします。実際に検証したのはWindows版4.5.1です。[公式ダウンロード](https://godotengine.org/download/archive/4.5.1-stable/)
2. プロジェクトを開き、**F5**を押します。新しい起動シーンは `scenes/world.tscn` です。
3. ゲーム内の画面と操作説明は日本語です。システムフォントを使用します。

```sh
godot --editor --path .
godot --path .
```

論理解像度は1280×800、Compatibilityレンダラーです。地形・拠点・人物はGodotの描画機能による仮アートです。開始技術は中世後半の西洋水準というユーザーの定義に従い、正式なアートは後続の更新で扱います。

## 最初に試すこと

### 生活と生産を動かす

1. 自国の村の住民を選びます。ミラ・レン・エマ・ノアは初期の農業担当で、作業場へ向かいます。ユナ・カイを選び、右の仕事欄から伐採・採石を割り当てると別の生産を試せます。
2. 住民は地形を避けて作業場へ移動し、到着後に「労働」へ移ります。定員は農地4人、伐採地3人、採石場3人。兵士はこの段階では職業変更できません。
3. 直接の移動・巡回・命令解除は仕事を解除します。それまでに働いた時間は保持し、同じ時間を二つの仕事へ使いません。人物欄で本日の労働時間と私有在庫を確認できます。
4. **政治調整を開始**し、現物税率を入力して**適用**します。食料不足時の自動配給もここで変更できます。調整終了後、同じ時計で経済が進みます。
5. **選択した人物へ食料1を配給**で国庫から個人へ物資を移せます。配給は新しい生産や課税対象にしません。
6. 日末に労働を生産へ反映し、全員が食料を消費します。食料は仮暦の月6・月9の末に収穫します。月末に当月の生産分へ課税し、要求と実納入、消費、配給、不足、拠点維持を報告します。

実時間1秒＝30ゲーム秒を守るため、1日は通常速度で48実分です。通常プレイでは経済を数秒で決算しません。仕事の移動・労働時間・政治設定はすぐ確認できます。90日・360日の数値検証は下記の経済テストで行えます。

暦はユーザー承認の仮設定：30日/月、12か月/周期、開始年なし。開始季節を春とした試作で、春・夏・秋・冬を各3か月としています。人口は24成人のままです。死亡・出生・世帯・給料・市場はまだありません。

### 人物を動かす

1. 青緑の人物を左クリックします。丸い人物が住民、四角い人物が兵士です。ホイールで拡大すると選びやすくなります。
2. 陸地を右クリックすると移動を指示します。選択中の人物の経路と目的地を黄色で表示します。
3. 川の反対側を指定すると、中央の石橋を経由します。海・川の水面・崖には進入できず、島へ渡る陸路もありません。
4. **Space**または上部のボタンで世界を停止します。停止中に命令を出すことは可能で、移動は再開後に始まります。
5. **巡回先を指定**を押して陸地を右クリックすると、現在地と指定先を往復します。**命令解除**で待機に戻ります。

他国と無所属の人物は情報確認のみ可能です。国境を越えても人物の所属は変わりません。初期状態で自国・他国・無所属の各1人が自律巡回しています。

### 国境を交渉する

1. **同面積の試案を作る**を押すと、双方が地図面積12,000ずつ交換する初回の案が表示されます。**国境の提案を開始**から自分で編集することもできます。
2. 黄色い線の丸い点をドラッグして移動します。地理上の標石に近づけると点が吸着します。四角い両端は固定です。
3. 線の近くをダブルクリックして点を追加し、途中の点を右クリックして削除できます。編集モード中の右クリックは人物移動に使いません。
4. 青緑の領域は自国の取得、赤い領域は相手国の取得です。右側に交換面積と相手国の判断を表示します。
5. **相手国に提案する**で提出します。合意時に両国の領土を同時更新します。拒否された案は編集を続けられます。**提案を取り消す**では確定済みの領土は変わりません。

相手国の仮条件は「双方が土地を差し出し、相手国の取得面積が譲渡面積の95%以上」で、面積だけを判断材料にしています。数値と判断は `[PLACEHOLDER]` です。資源・地価・外交関係は次の段階で追加します。面積は地図座標の二乗であり、現実の面積単位とは対応していません。

## 操作一覧

| 操作 | 効果 |
| --- | --- |
| 左クリック | 人物または村・城塞の情報を表示 |
| 右クリック | 選択中の自国人物へ移動命令。巡回指定中は往復地点を指定 |
| 中ボタンのドラッグ | 地図を移動 |
| マウスホイール | カーソル位置を基準に地図を拡大・縮小 |
| Space / 一時停止 | 世界全体を停止・再開 |
| 1× / 2× / 4× | 共通時計の進行速度を変更 |
| 地図全体を表示 | カメラを初期の範囲へ戻す |
| 初期化 | 人物・命令・国境・時計を初期状態へ戻す |
| 世界を保存 | 共通時計、人物・命令、確定国境・編集中の提案、履歴を保存 |
| 読み込む | 保存した世界を復元。失敗時は現在の世界を維持 |
| 政治調整を開始 / 終了 | 世界を停止して土地交換を調整。終了後は通常操作へ戻る |
| 仕事欄 / 割り当て | 自国住民を農業・伐採・採石へ割り当て。解除も選択可能 |
| 現物税 / 適用 | 政治調整中に0〜100%の共通現物税率を変更 |
| 自動配給 | 政治調整中に食料不足者への国庫支給を有効・無効にする |
| 食料1を配給 | 選択中の自国人物へ国庫の食料を移す |

右のパネルは縦スクロールできます。記録欄は直近の8件を表示し、状態内では50件を保持します。保存は1スロットの `user://world-save.json`。Windowsの通常起動では `%APPDATA%/Godot/app_userdata/Frontier Council/` に置かれます。前回の保存は `.bak` に保持し、最新ファイルが破損していればバックアップへ戻ります。読み込みは停止・速度も復元するため、進行中に保存した世界は進行中として再開します。初期化は保存を消しません。

通常速度は**実時間1秒＝ゲーム内30秒**。2倍速60秒、4倍速120秒です。表示は経過日数と時分秒で、ゲーム内1日は通常速度で実時間48分です。移動の仮速度は通常速度で従来の見た目を維持しています。

政治調整中はSpaceでも時間を再開できません。土地交換の提案開始でも政治調整へ入ります。提案を確定または取り消した後、**政治調整を終了**を押してください。開始前から手動停止していた場合は終了後も停止します。政治調整の周期は未定義なので、現在は任意に開始する方式です。

v0.2.1/v0.2.2の保存も読み込めます。人物と命令は維持し、旧時間単位は30倍へ移行します。編集中の提案があれば政治調整中として復元します。旧保存には経済がないため、読み込んだ経過日で新しい在庫と経済を開始し、過去の消費・税を遡って実行しません。旧人物の仕事は未割当です。

v0.3では国庫と個人在庫、税率・配給設定、仕事と作業位置、日内の労働、農作業の蓄積、資源残量、忠誠・体力・食料不足、直近12か月の決算を保存します。

## 地形と領土の制約

- 2国家にそれぞれ住民6人・兵士4人、無所属村に住民4人の合計24人です。
- 各国の村と城塞、北の無所属村、山、川、橋、無所属の沖合島を固定配置しています。
- 経路探索は地形の輪郭と障害物を結ぶ不可視の経路グラフを使います。土地の所有権は経路の通行可否に影響しません。
- 村・城塞の譲渡、無所属地域の編入、飛び地は取引対象外です。
- 初期版の国境は北から南へ点を並べる折れ線です。折り返し、自己交差、海岸の横断、村・城塞の敷地への接近を拒否し、両国の領土に重複や空白ができないよう検証します。
- 国境の編集点は最大32点です。これは試作の編集・計算負荷を抑える制限で、完成版の国境の自由度を確定するものではありません。

実装済み：地図・人物・政治調整・土地交換・保存に加え、食料・木材・石材、農業・伐採・採石、実際の労働時間、季節収穫、日次の食事、個人と国庫の在庫、月次の現物税・実納入・不納、忠誠・体力・食料不足と生産への影響、配給、拠点維持費、有限の採石場と森林再生、経済状態の保存・復元。

後続段階：新しい土地の開拓と未知の鉱床、鉄・工具・衣料・金銀、輸送・市場・交易、民の自主的な仕事・事業選択、委任・給与・登用・雇用・育成・待遇、規則編集と権限、人口、金融、補給・戦争・滅亡、外交関係・経済圏・国際組織、正式アート、Steam配布。経済・金融・人口・蒸気技術の方向と仮数値は [経済設計](docs/economy-design.md) に整理しています。

現物税・配給は集落圏内の即時の帳簿移転として抽象化しています。実物の輸送は次の段階です。拠点の維持不足は決算で通知し、建物損壊・機能低下はまだありません。食料不足は能率と忠誠へ影響しますが、この更新では人物の死亡や国家滅亡にしません。生産・税・能力・初期在庫はすべて調整用の仮設定です。

最終像と次の定義項目は [設計・ロードマップ](docs/world-design.md)、構造と仮数値の理由は [実装メモ](docs/world-architecture.md)を参照してください。

## v0.3.1：手動の陸上輸送

自国の住民を選び、右側を「物資の陸上輸送」までスクロールします。上の選択欄が出発元、下が届け先です。国庫と自国人物の私有在庫の間、または人物同士で食料・木材・石材を運べます。国庫の受渡地点は自国の村、個人の受渡地点は本人の現在位置です。初期状態でユナを選び、国庫→ミラ・食料1を指示すると短時間で配送を試せます。

指示時に出発元の在庫を予約します。担当者が受取地点へ移動し、荷物を積み、届け先まで実際に歩きます。川は橋を通り、陸路がない注文は拒否します。受取人が動いた場合は現在地へ経路を更新します。積載中の人物には黄色い荷物マークを表示します。

「命令解除」は積込前なら予約を戻して取消、積込後なら荷物を保持して停止します。「輸送を再開」で続行、「取消・返送」で予約取消または出発元への物理的返送を行います。輸送担当者への移動・巡回・仕事変更は荷物の処理を先に求めます。停止・政治調整中も注文は入力でき、配送は時間再開後に進みます。

積載上限は `5 + 体力 / 10`、受渡距離3、受取人の移動による経路再計算の目安20地図単位。すべて `[PLACEHOLDER]` です。体力による仕事選択と経路追従を検証するための数値で、重量の実単位や物流バランスを確定するものではありません。

税、従来の配給ボタン、自動配給は現在も即時の帳簿移転です。この更新では手動配送を追加しました。自動輸送・海運・貨幣・取引価格・外国との交易は後続です。輸送完了を新たな生産所得として課税しません。

保存形式はversion 4。予約・積載・停止・返送中の荷物を復元し、version 3は荷物なしで移行します。version 4で輸送情報が欠ける場合や、不正な量・担当者・受渡口座は読み込みを拒否します。

```sh
godot --headless --path . --script tests/transport_smoke.gd
godot --path . --script tests/transport_preview.gd -- SCREENSHOT_DIRECTORY
```
