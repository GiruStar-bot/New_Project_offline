# Frontier Council — 国家運営・部隊指揮の最小プロトタイプ

Godotで起動できる2D・シングルプレイヤーの骨組みです。領土マップで作戦を選び、別の戦場画面で将軍の師団を指揮し、その結果を領土・兵力・士気・補給・経済へ反映します。通常NPCへの占領・防衛の委任も試せます。外部AI、ネット接続、APIキーは不要です。

**戦闘、経済、数値、世界観、拠点名、勝利条件はすべて仮実装です。** 完成版の仕様を確定するものではありません。ゲーム画面は暫定的に英語、説明は日本語です。

## 起動

1. [Godot公式の4.5.1 Standard版](https://godotengine.org/download/archive/4.5.1-stable/)を用意します。.NET版や追加プラグインは不要です。実動作を検証したのはWindows版4.5.1です。
2. Godotのプロジェクトマネージャーで「インポート」を選び、このフォルダの `project.godot` を指定します。
3. プロジェクトを開き、**F6ではなくF5**でゲーム全体を実行します。起動シーンは `scenes/main.tscn` です。

コマンドラインからも実行できます。以下の `godot` はGodot実行ファイルへのパスで置き換えてください。

```sh
godot --editor --path .
godot --path .
```

論理解像度は1280×800、描画はCompatibilityレンダラーです。画像・フォントなどの外部アセットなしで画面を構成しています。Steamでの配布を目指す方針は維持しますが、この段階ではGodotプロジェクトとして実行してください。

## 最初に試す操作

1. 最初は自国領 `Breadbasket` に師団がいます。金色の枠が選択中の領土です。
2. 隣接する中立領 `Crossroads` をクリックし、右の **Lead attack** を押します。出撃にはTreasury（国庫）8、Supply（師団補給）12以上が必要です。
3. 別の戦場画面で **ENEMY INTENT**（敵の次の行動）を読み、Attack / Defend / Regroup / Retreatを選びます。1クリックで1ラウンドが進みます。
4. 決着後の **Return to council** を押すと、結果を適用してマップへ戻ります。勝利すると領土の色が自国色になり、師団がその領土へ移動します。国のターンも1回進みます。
5. **Reinforce** で兵力・士気・補給を回復してから、隣の `Red Plain`、その先の山岳拠点 `Citadel` を目指します。
6. 自分で戦場を指揮する代わりに **Delegate occupation to Mira** → **End turn** を押すと、ミラ将軍が戦闘を実行します。Council Recordに判断と結果が残ります。

敗北しても師団は補充できます。**New campaign** は即座に初期状態へ戻すボタンです。保存機能はまだありません。

## 画面と操作

マップは5列×3行、陸地13マスと海2マスです。青緑が自国、赤が敵国、灰青が中立領。`[DIVISION]` が師団の所在です。マスのクリックで選択し、右側のボタンで実行します。実行できない操作は無効化され、領土を選んだ際に画面下へ理由を表示します。

| 操作 | 動作・費用 |
| --- | --- |
| Lead attack | 隣接する敵国・中立領に出撃。国庫8を消費し戦場画面へ。中立領にも民兵がいる仮ルール。 |
| Move division | 上下左右に隣接する自国領へ移動。補給2を消費。国のターンは進まない。 |
| Delegate occupation to Mira | 選択した隣接領土への占領を予約。End turnでNPCが戦闘を実行。自動経路探索はない。 |
| Delegate defense here | 師団の現在地の防衛を予約。毎ターン士気8を回復し、その領土が襲撃対象なら被害を軽減。移動・出撃で解除。 |
| Reinforce | 国庫12・食料15を消費。兵力+30、士気+20、補給+35、それぞれ上限100。ターンは進まない。 |
| End turn | 予約したNPC作戦を実行し、収入と維持費を計算。待機のみでも1ターン進む。 |
| New campaign | 戦闘中も含めてキャンペーンを初期化。 |

操作記録は最大50件を保持し、画面下のスクロール領域に直近の記録を表示します。

## 採用した時間の扱い

最小版では**国のターンと戦闘ラウンドを分けたターン制**を採用しました。敵の予告・地形・補給を観察して判断でき、経済と作戦の因果関係をテストしやすいためです。リアルタイム制や一時停止式を完成版の仕様として否定するものではありません。

- マップの領土選択・NPCへの予約だけでは時間が進みません。
- 移動と補充は資源を使う即時操作です。
- プレイヤー戦闘は決着後に結果を反映すると国のターンが1回進みます。
- NPC戦闘はEnd turnの中で完結し、同じ操作でターンが二重に進むことはありません。

## 仮の経済・地理

- 自国の沿岸領土は毎ターン国庫+7、その他の陸地は+4です。
- 平地は食料+10、その他の陸地は+3です。
- 師団の維持費は毎ターン国庫6・食料12です。占領した領土は結果反映時の収入から計算に入ります。
- 食料が0になると士気を12失います。食料と師団補給は別の値です。補充時に食料を使って補給を回復します。
- 海は通行・占領不可です。斜め移動や、海を越える輸送は未実装です。
- 山岳では通常の攻撃ダメージを7軽減します。森林は現段階では地名表示と低い食料生産のみで、独自の戦闘補正はありません。
- 国のターン番号が3の倍数になると、敵領に隣接する最初の自国領（マップID順）へ簡易的な国境襲撃が発生し、国庫8を失います。そこをミラが防衛していれば損失は2です。これは敵の戦略AI・領土奪還の代用となる仮処理です。

## 仮の戦闘

戦闘は再現可能な決定的計算で、乱数を使いません。敵の行動は基本的に「攻撃→防御→攻撃」の周期で、士気が低いと再編します。次の行動を戦場画面に表示します。

| 指示 | 効果 |
| --- | --- |
| Attack | 兵力と士気に応じた攻撃。補給8を消費。敵防御や山岳で威力が下がる。 |
| Defend | 被害を約1/3に軽減し、攻撃してきた敵へ反撃。士気+3、補給4を消費。 |
| Regroup | 攻撃をやめ、士気+16。ただし通常より被害が増える。補給4を消費。 |
| Retreat | 兵力4・士気8を失って即時撤退。領土と師団の所在は元のまま。 |

補給12未満では通常攻撃が弱くなり、被害が増えます。被害は士気も低下させます。味方の兵力・士気が0になると敗北、敵の兵力・士気が0になると勝利。双方が同時に0になる場合は味方の敗北を優先します。10ラウンドで決着しなければ日没による撤退です。戦闘後も味方の損耗と敵守備隊への損害が残りますが、未占領領土の守備隊には下限15を設けています。

ミラは兵力28未満または補給4未満なら撤退し、敵の攻撃を一部防御し、士気が低く安全なタイミングなら再編します。複数NPCの個性比較はまだありませんが、判断処理は独立したGDScriptにあります。

## 構成と拡張先

| ファイル | 責務 |
| --- | --- |
| `project.godot` / `scenes/main.tscn` | Godot設定・起動シーン。 |
| `scripts/main.gd` | マップと戦場の画面切り替え、入力の仲介。ゲーム状態の所有者。 |
| `scripts/game_state.gd` | 領土、経済、師団、作戦予約、戦闘結果の反映。 |
| `scripts/battle_model.gd` | 戦闘のラウンド計算・決着。画面に依存しない。 |
| `scripts/npc_commander.gd` | 通常NPCの判断。GDScriptのみ。 |
| `scripts/ui/strategy_view.gd` | 領土マップと国家運営画面。意図をシグナルで通知。 |
| `scripts/ui/battle_view.gd` / `battlefield.gd` | 戦場画面・仮の部隊図。戦闘計算は行わない。 |
| `scripts/ui/ui.gd` | 色・テーマ・表示部品。 |
| `tests/smoke.gd` | ゲームルール・NPC・画面接続の自動テスト。 |
| `tests/preview.gd` | 実際のGodotビューポートをPNG保存する検証用スクリプト。 |

将来的な外部AIは、NPCが返すコマンドを別の判断元から取得する形に拡張できます。認証・課金・API通信をゲーム状態や画面へ組み込んでいません。外交や技術・複数師団は状態層、詳細戦闘は戦闘層から段階的に拡張してください。

## 検証

```sh
godot --headless --editor --path . --quit
godot --headless --path . --script tests/smoke.gd
# 実画面の描画に対応した環境で、既存の出力フォルダを指定
godot --path . --script tests/preview.gd -- /absolute/path/to/output
```

- エディターによるプロジェクト読み込み：終了コード0、スクリプトエラーなし。
- 自動テスト：**46項目、失敗0、終了コード0**。海・飛び越し・自国への攻撃拒否、勝利・敗北・撤退、損耗、二重適用防止、地形と補給、防御・再編、経済、NPC占領と防衛、最終拠点までの到達、実際のUIボタン信号からの画面切り替えを確認。
- 実描画：戦略マップ、戦場、占領結果の3画面をPNGとして取得し、1280×800のビューポートで表示を目視確認。使用GPUはIntel HD Graphics 620、Compatibility / ANGLE。
