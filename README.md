# Frontier Council — マスのない国家世界 / v0.2

Godot製の2D・シングルプレイヤーゲームです。現在は**地図・人物移動・土地交換**を遊べる試作です。地図上にマス目はなく、24人が連続した座標で移動します。世界全体の時間を止めて命令を出し、地図上の国境を編集して相手国へ交換案を提出できます。外部AI、APIキー、追加プラグインは不要です。

最終目標は、国家が存続する限り進むサンドボックスです。軍事・外交・資源・経済圏・国際組織による運営、人材の登用・雇用・育成と業務の自動化を段階的に追加します。**その最終像のすべてを、この試作で実装したわけではありません。** 自国滅亡による終了は戦争・統治の段階で定義・実装します。新しい世界にはCitadel占領による終了はありません。

## 起動

1. Godot **4.5.1 Standard**で、このフォルダの `project.godot` をインポートします。実際に検証したのはWindows版4.5.1です。[公式ダウンロード](https://godotengine.org/download/archive/4.5.1-stable/)
2. プロジェクトを開き、**F5**を押します。新しい起動シーンは `scenes/world.tscn` です。
3. ゲーム内の画面と操作説明は日本語です。システムフォントを使用します。

```sh
godot --editor --path .
godot --path .
```

論理解像度は1280×800、Compatibilityレンダラーです。地形・拠点・人物はGodotの描画機能による仮アートです。正式な時代背景やアートスタイルを確定するものではありません。

## 最初に試すこと

### 人物を動かす

1. 青緑の人物を左クリックします。丸い人物が住民、四角い人物が兵士です。ホイールで拡大すると選びやすくなります。
2. 陸地を右クリックすると移動を指示します。選択中の人物の経路と目的地を黄色で表示します。
3. 川の反対側を指定すると、中央の石橋を経由します。海・川の水面・崖には進入できず、島へ渡る陸路もありません。
4. **Space**または上部のボタンで世界を停止します。停止中に命令を出すことは可能で、移動は再開後に始まります。
5. **巡回先を指定**を押して陸地を右クリックすると、現在地と指定先を往復します。**命令解除**で待機に戻ります。

他国と無所属の人物は情報確認のみ可能です。国境を越えても人物の所属は変わりません。初期状態で自国・他国・無所属の各1人が自律巡回しています。

### 国境を交渉する

1. **同面積の試案を作る**を押すと、双方が地図面積12,000ずつ交換する初回の案が表示されます。**国境の提案を開始**から自分で編集することもできます。
2. 黄色い線の丸い点をドラッグして移動します。地理上の標石に近づけると点が吸着します。四角い両端は固定です。
3. 線の近くをダブルクリックして点を追加し、途中の点を右クリックして削除できます。編集モード中の右クリックは人物移動に使いません。
4. 青緑の領域は自国の取得、赤い領域は相手国の取得です。右側に交換面積と相手国の判断を表示します。
5. **相手国に提案する**で提出します。合意時に両国の領土を同時更新します。拒否された案は編集を続けられます。**提案を取り消す**では確定済みの領土は変わりません。

相手国の仮条件は「双方が土地を差し出し、相手国の取得面積が譲渡面積の95%以上」で、面積だけを判断材料にしています。数値と判断は `[PLACEHOLDER]` です。資源・地価・外交関係は次の段階で追加します。面積は地図座標の二乗であり、現実の面積単位とは対応していません。

## 操作一覧

| 操作 | 効果 |
| --- | --- |
| 左クリック | 人物または村・城塞の情報を表示 |
| 右クリック | 選択中の自国人物へ移動命令。巡回指定中は往復地点を指定 |
| 中ボタンのドラッグ | 地図を移動 |
| マウスホイール | カーソル位置を基準に地図を拡大・縮小 |
| Space / 一時停止 | 世界全体を停止・再開 |
| 1× / 2× / 4× | 共通時計の進行速度を変更 |
| 地図全体を表示 | カメラを初期の範囲へ戻す |
| 初期化 | 人物・命令・国境・時計を初期状態へ戻す |

右のパネルは縦スクロールできます。記録欄は直近の8件を表示し、状態内では50件を保持します。セーブはまだありません。

## 地形と領土の制約

- 2国家にそれぞれ住民6人・兵士4人、無所属村に住民4人の合計24人です。
- 各国の村と城塞、北の無所属村、山、川、橋、無所属の沖合島を固定配置しています。
- 経路探索は地形の輪郭と障害物を結ぶ不可視の経路グラフを使います。土地の所有権は経路の通行可否に影響しません。
- 村・城塞の譲渡、無所属地域の編入、飛び地は取引対象外です。
- 初期版の国境は北から南へ点を並べる折れ線です。折り返し、自己交差、海岸の横断、村・城塞の敷地への接近を拒否し、両国の領土に重複や空白ができないよう検証します。
- 国境の編集点は最大32点です。これは試作の編集・計算負荷を抑える制限で、完成版の国境の自由度を確定するものではありません。

## 旧ターン制の試作

`scenes/main.tscn` と既存のスクリプトは維持しています。Godotでこのシーンを開き、**F6**で独立して実行できます。新しい世界と旧試作の時計・領土・部隊は共有しません。

```sh
godot --path . res://scenes/main.tscn
```

旧版の操作と検証は [旧プロトタイプの説明](docs/legacy-prototype.md)にあります。その資料の「起動シーン」は旧版についての記載です。

## 検証

```sh
godot --headless --editor --path . --quit
godot --headless --path . --script tests/world_smoke.gd
godot --headless --path . --script tests/world_input.gd
godot --headless --path . --script tests/smoke.gd
# 描画可能な環境と既存の出力フォルダで実行
godot --path . --script tests/world_preview.gd -- /absolute/output/directory
```

2026-10-02、Windows / Godot 4.5.1 Standardで、新世界118項目・GUI入力経路11項目・旧版46項目、**計175項目が失敗0**でした。新世界の選択・移動・経路、停止・速度変更、領土交換の幾何と95%判定、GUIからの編集、初期化後の信号接続を確認しています。

Godotのビューポートへマウス・キー入力を送り、実際のGUI配送経路も検証しました。OS上のマウスポインターを使う人間のプレイテストとは区別しています。ネイティブ描画でもこの入力テストを実行しています。

実描画では地図、移動経路、国境提案、合意後、橋の拡大、拒否された案、小さい物理ウィンドウの7画面を保存・目視確認しました。基準は1280×800の論理解像度で、小さい物理ウィンドウは1152×720です。Intel HD Graphics 620ではOpenGLのドライバー警告後にANGLEへ自動切り替えされ、描画は成功しました。

制限環境でOS証明書の読み取りエラーが出るため、最終のモデル・入力・旧版テストはOS読み取りが許可された環境で実行しました。そこではスクリプトエラー・証明書エラー・リソース漏れ警告なしで完了しています。
