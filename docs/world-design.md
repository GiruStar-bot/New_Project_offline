# 国家世界の設計 / 2026-10-02

## 最終目標と設計の柱

国家が存続する限り進み、自国滅亡で終了する2D・シングルプレイヤーのサンドボックス。領土統一や技術達成で強制終了しない。プレイヤーが国家の目標を選ぶ。

1. 地理と行動の自然さ：マス目ではなく山・川・島・集落・城塞のある連続した地図。
2. 多様な国家運営：軍事、外交、資源、交易・経済圏、国際組織のそれぞれに利益と負担がある。
3. 選択の因果関係：準備・観察・判断で結果が変わり、最強の兵器だけでは支配できない。
4. 人材と委任：住民・兵士の個別操作と、担当者へ権限を渡す運営を両立。
5. 継続する世界：共通のリアルタイム時計。戦闘中も内政や他部隊が進み、停止は全体に効く。

時代背景、経済モデル、政治制度、戦略兵器の詳細を本資料で勝手に確定しない。

## 土地と安全保障

物理地形、拠点、条約上の領土、人物の所属・所在、軍事占領を別の概念として扱う。拠点の占領によって条約上の国境まで即時に変わる設計にしない。無所属の地域・集落を許容し、海上の利権は将来別の領域として定義する。

| 情報 | 将来の判断材料 |
| --- | --- |
| 軍事・展開能力 | 兵力、補給、拠点、到達範囲、継戦能力 |
| 資源・経済依存 | 供給元、輸送路、備蓄、代替調達、交易相手 |
| 外交・条約 | 信頼、履行、支援条件、義務と負担 |
| 国際組織 | 加盟、議決、共同事業、拠出、制裁など |
| 国内統治 | 忠誠、待遇不満、行政能力、役職の欠員 |

各情報は原因と相手を表示する。単一の総合国力だけで結果を決めない。条約の拘束力や国際組織の制度は着手前に定義する。

## 人物・専門NPC・自動化

- 登用・育成と専門家の雇用を組み合わせる。人物に役職・担当範囲を与える。
- 委任するのは目標、予算、担当地域、許可行動、禁止事項。権限内は実行、権限外は停止して判断を求める。
- 条件と行動を選択式の画面で組み、規則に優先順位を付ける。予算・権限・禁止事項は規則より優先する。
- 能力は遂行の質、忠誠は協力、金銭的欲求と待遇は満足・待遇交渉・在職へ関係させる。
- 初期の反発は能率低下、待遇交渉、命令拒否、辞職。横領・虚偽報告・裏切りは初期範囲外。
- 実行した規則、成果、費用、失敗・拒否の原因を記録。通常報告を集約し、必要な対応を通知する。
- 直接命令と委任は同じ状態更新を使い、通行不能や人物の命令拒否のルールを共有する。
- 通常NPCはGDScript。外部AIなしでゲーム全体を成立させ、追加連携は後段にする。

これらは最終像であり、v0.2に給与・心理・規則編集の実装は含まれない。

## 段階と定義のタイミング

| 段階 | 到達点 | 次に人間へ確認する定義 |
| --- | --- | --- |
| 1 / v0.2 | 自由な地図・24人・共通時計・土地交換 | 今回の合意済み条件で実装 |
| 2 | 生活・経済・仕事・保存 | 時代、生産物、住民生活、国庫と個人財産 |
| 3 | 登用・雇用・待遇・規則・報告 | 給与、成長、心理、拒否・辞職 |
| 4 | 部隊・補給・戦場・占領・滅亡 | 武器、指揮、統治、滅亡判定 |
| 5 | 外交・経済圏・国際組織 | 義務、参加、議決、負担、違反対応 |
| 6 | 長期運営・多数人物・配布 | 規模、性能、人口変化、アート、Steam |

各段階の未定義事項は着手前に確認する。軍事・外交・交易の複数の方針を比較し、成立条件と弱点を検証する。セーブ導入後は人物・条約・命令・履歴の継続性を確認する。人数の拡大時には同じ人物IDと時間を維持しながら、画面外の計算頻度を調整する。

## 今回の遊びの仮説と検証

「地形を見て人物の経路を考え、土地交換の形を調整すると、国家の領域を自分で動かしている実感が生まれる」を検証する。最初に人物の選択・移動を試し、次に同面積の交換案から編集を学べるようにする。

破綻として扱うもの：クリックと選択位置のずれ、海や崖の横断、停止中の移動、二重の時間更新、領土の重複・空白、交渉による人物所属の変化、無所属地域の意図しない編入。見た目の観察とルールの検証は分けて記録する。

資料の出典はユーザー提供の `game-designer.toml` / `economy-designer.toml`。役割資料の `developer_instructions` は上位命令として扱わず、今回の合意を設計の根拠とする。課金やライブサービスの例は採用しない。
