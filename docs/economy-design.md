# 生活・資源・国家財政の設計 / 2026-10-02

## 状態と根拠

ユーザーの今回の定義と追加回答を記録する設計書。確定事項、実装者からの提案、未定義事項を区別する。数値はすべてゲーム用の `[PLACEHOLDER]`。歴史資料からゲームの生産量・税率を導いたと主張しない。

v0.3の実装済みは地図・人物・保存・30倍時計・政治調整に加え、食料・木材・石材の仕事、生産と生活消費、季節収穫、個人と国庫の在庫、現物税・不納・配給・月次決算、忠誠・体力・食料不足による能率、資源残量、経済の保存。金融、土地開拓、鉱床発見、所有権の交渉、国籍変更、海路などの以下の最終像は未実装。既存の越境自由の陸路に検知・信頼低下・戦闘はまだない。

添付の game-designer.toml / economy-designer.toml は設計の参考資料。選択の目的、資源の流入と消費、数値の仮設定と検証を採用する。課金・シーズン制は採用しない。

## ユーザーにより確定した方向

- 開始時の技術は中世後半の西洋水準。人の労働が中心。移動は陸路・海路。
- 無所属、自国、協定相手、協定のない他国にも移動できる。道路優先・最短経路・手動経由点を選ぶ。無協定での移動が衛兵などに発見されると相手との信頼が低下し、好戦的な集団なら小競り合いに発展し得る。
- 体力のある人を兵士・伐採・採掘に配分し、知力のある人を育てて開発・委任へ使う。
- 金・銀・鉱石は有限。農業は季節・土壌、森林は伐採・再生に制約される（追加回答で確定）。資源の位置は未探索の地図に種類別シンボルを出さず、開拓・調査によって発見する。
- 川・井戸などの水源と土地条件を使って農地を開く。人材の投入で灌漑を建設する。
- 国庫と個人財産を分ける。農民の生産物に対する現物徴収割合を設定し、忠誠と負担によって不納・反発が起きる。再分配と刑罰も選択肢。
- 国家が投資して開発した鉱山は公営で収益を受ける。民の発見・開発には私有権、利益配分、保護契約、他国の提示条件、没収の影響が関わる。
- 民が鉱山の保護先を他国へ替えると、その民の国籍も保護国に替わる（追加回答で確定）。国境はこの契約だけでは変更しない。未開発の発見と所有権成立の条件は別途定義する。
- 公営の維持費・労働者待遇、民営の求人・報酬・危険に対する民AIの判断、強制労働の選択を扱う。
- 金銀貨、紙幣、為替、信用に基づく貨幣、銀行・融資・利息・給付を段階的に追加する。
- 蒸気機関は後続技術。研究費・知的能力・導入投資が必要。鉄道、蒸気船、工場、採掘に導入し、技術提供も外交交渉に使う。
- 家の新築・増築で収容力を増やす。家計の余力を出生へ関係させる。酒・ワイン、遺跡と観光、資源輸出、貿易中継の手数料も後続の経済活動にする。
- 政治の項目を調整するターンでは世界時間を停止する。それ以外は通常速度で実時間1秒につきゲーム時間30秒。その他の命令はその場で入力する（追加定義）。

## 確定した時間と政治調整

通常速度は30ゲーム秒/実秒、2倍速は60、4倍速は120。1日は通常速度で実時間48分。経済試作はユーザーの回答により30日/月・12か月/周期の仮暦を採用。1か月は通常速度24時間、2倍速12時間、4倍速6時間。開始年は付けず経過月を表示する。春を開始位置とする試作で、各季節は3か月。

政治調整中は手動の一時停止と別の理由で世界時計を止める。Spaceや速度変更でこの停止を解除できない。調整前に手動停止していた場合は、政治調整終了後も手動停止を維持する。移動命令や地図操作は停止中も入力でき、人物は再開後に動く。後続の生産・戦場・月次処理も同じ時計に接続する。

調整ターンの周期が未指定なので、現在は「政治調整を開始」「政治調整を終了」で任意に入る方式。土地交換の編集開始も自動で政治調整へ入る。未確定の国境提案がある間は終了を拒否し、確定か取消を求める。合意・取消だけでは政治調整を終えず、終了ボタンで通常操作へ戻る。v0.3では共通の現物税率と不足時の自動配給を調整する。

## 資源構成の提案

初期の在庫は9種類。これらを一度に大量配置せず、最初は食料・木材・石材から動作確認し、加工業と金銀を順に接続する。金銀の用途は貨幣・交易の更新で成立させる。金鉱山を発見しただけで架空の資金を追加しない。

| 在庫 | 主な流入 | 消費・用途 | 設計上の選択 |
| --- | --- | --- | --- |
| 食料 | 水源近くの農地、後続の漁場・牧畜、輸入 | 住民の食事、兵士の補給、種・備蓄・腐敗損失 | 徴収と生活確保、収穫期と備蓄 |
| 木材 | 森林の伐採、輸入 | 家・船・道具・灌漑・燃料・修繕 | 伐採と森林再生、建設と燃料 |
| 石材 | 有限の採石場、輸入 | 家・倉庫・城塞・道路・灌漑 | 長持ちする施設と建設負担 |
| 鉄鉱石 | 有限の鉱床、輸入 | 製鉄 | 採掘・輸入・輸送の配分 |
| 鉄材 | 鉄鉱石と燃料を使う製鉄、輸入・回収 | 工具、後続の武器・装甲・設備 | 民生の生産力と軍備 |
| 工具 | 鉄材・木材を使う工房 | 農業・伐採・採掘・建設で摩耗 | 生産設備を維持する人員 |
| 衣料 | 繊維産地と縫製の集約工程、輸入 | 生活、防寒、後続の軍装 | 気候と生活費、生産の多様化 |
| 金 | 有限の鉱床、輸入 | 貨幣鋳造・準備資産・交易、後続の工芸 | 所有と保護、貨幣と輸出 |
| 銀 | 有限の鉱床、輸入 | 貨幣鋳造・準備資産・交易、後続の工芸 | 金と異なる供給・取引条件 |

初期は食料を生活用の集約物資、衣料を繊維原料から完成品までの集約製品として扱う。衣料の生産には牧草地・繊維作物用地と加工労働が必要で、無条件に物を生成しない。製鉄の燃料用木材は木炭への加工を工程に含めるが、木炭在庫は初期には分けない。この抽象化は仮説であり、産業の判断が不足するなら繊維・布・木炭を独立させる。

水は水源・季節流量・灌漑到達範囲、労働力は人の時間、知識は人材と技術として保持する。全部を倉庫の同じ資源へ変換しない。地質の埋蔵量、森林の立木量、農地の肥沃度と収穫量、既に採取した在庫を分ける。

後続の追加候補：家畜・馬（運搬と騎兵）、羊毛・亜麻・布、塩（保存・交易）、穀物・葡萄・酒・ワイン（品質と産地）、石炭（蒸気）、紙（行政と紙幣）、武器・防具（装備）。新しい用途が成立する更新で導入する。

## 生活、徴収、統治の提案

徴収対象は当期に実際に取得した生産物。輸送・所有者変更・在庫の移動を再度生産と見なして課税しない。前年在庫を毎月徴収する処理も設けない。季節収穫のない月は農業生産税も発生しない。月末に実績を集計する。

食料生産 → 種の確保 → 課税対象の確定 → 実際の納入 → 私有残量 → 食事と販売、という順を提案する。種の控除や最低生活分の控除は政策として定義する。国が生産した資源は国庫へ直接入り、そこから給与・現物支給を出す。民の生産物はまず民の所有になり、現物税と契約分だけ国へ移す。

忠誠は税を払える能力ではない。納税可能量は在庫で決まり、納付への協力は忠誠、生活圧迫、公平感、行政の到達、処罰への恐怖で変わる。要求、実納、未納を別々に報告する。

再分配は国庫の物を民の家計へ移す。飢餓・欠乏を減らして満足や信用へ影響する。刑罰は短期の納付圧力と長期の不満・人的損失を別に扱い、「刑罰で忠誠が上がる」処理にしない。極端な刑罰と無償労働が恒久的に最適になるならバランス破綻と判定する。

公営・民営の比率は画面の集約値にできるが、内部には別の設定を持つ：施設所有、土地・鉱業権、税率、利益分配、求人給与、安全投資、強制労働の許可、移転・国籍変更の制度。所有形態と政治体制を同一視しない。

## 隠れた資源と鉱山の権利

未探索の鉱床は地質状態に存在する。画面には金銀シンボル、種類別ツールチップ、未発見資源による交換価値を出さない。調査や農地開拓の投入、技術と人物能力によって地質へ到達する。高忠誠の民からは報告が届く。低忠誠だから必ず隠すとするか、報告・留保の詳細は後続の民AIで決める。

発見者、土地所有者、開発出資者、操業者、利益受取人、保護国、領土の主権国を別に持つ。プレイヤーによる指示だけで私有地が無償で公有になる仕様にはしない。未請求地で国家が出資した開発を初期の公営ケースとし、私有地は購入・契約・没収の判断に接続する。

他国との保護契約が成立したら、利益割合・保護義務・本人の国籍を同時更新する。鉱山位置・国境・現地在庫は動かさない。本人の所在も国籍変更で瞬間移動させない。契約拒否や取消は現状維持。自国領内の他国籍所有者に対する税、保護国の部隊通行、領土国の同意、没収時の他国との紛争は外交段階で明示する。

没収は権利と資産の移転であり新しい富の生成ではない。本人・他の民の財産保障への信頼と保護国との関係に影響する。未発見鉱床は保存・復元しても位置・残量が変わらず、読み込みで再抽選しない。

## 貨幣・銀行・為替の提案と史実との区別

段階は現物財政 → 金銀貨と市場 → 兌換紙幣・銀行 → 信用貨幣。金銀産出は新規の資産流入、保有金銀は準備資産、紙幣は発行残高、預金・貸出は貸借関係として分ける。鋳造した金銀を原料在庫にも残して二重計上しない。

月の金銀産出量だけで紙幣価値を決めない。兌換段階では発行残高に対する利用可能準備、交換約束と履行、決済需要が重要。信用貨幣では税として受け取る制度、価格の安定、物資の供給、政府と銀行の支払能力を扱う。紙幣発行で兵士の食料や鉄が物理的に増えるわけではない。

銀行は現金・準備、預金負債、貸出資産、自己資本を分ける。最初の銀行試作は保有貸付資金の範囲で貸す簡略モデルとし、信用創造を後続の別段階にする。融資の実行は国の利益ではなく、返済元本も利息収入と区別する。利息は借り手から貸し手への移転。給付も実在資金か発行のどちらで賄うか記録する。

民AIは貸出金利だけで起業しない。予想売上、原料費、賃金、税、安全投資、元利返済、本人の能力・危険への選好、販路を評価する。低金利でも需要や採算がなければ借りず、高金利でも高収益の計画なら借り得る。延滞・貸倒れ・取り付けへの処理を金融更新の完成条件にする。

為替は金銀生産・準備だけでなく、輸出入の決済、他国通貨需要、信用によって動く提案。最初は計算可能な簡略式で要因を表示し、実際の為替を正確に再現すると主張しない。式とパラメータは金融更新前に定義する。

史料：英国公文書館の税資料は財産に対する分数税、人頭税などを区別し、関税資料は貿易に対する徴収を示す。本ゲームの月次農業現物税はそれら全部を再現するものではなく、ユーザーの希望に合わせた抽象モデル。人口が増えれば自動的に税収が同率で増えるとはしない。課税対象の生産・所得・取引と徴収能力を使う。

## 人口と家計の提案

人物の能力とは別に、世帯、年齢、扶養、居住先、家計の資産・所得・支出を持つ。住居の空き、食料、家計の余力を出生の条件へ使うが、一定財産を超えた瞬間に毎月成人が生成される処理にはしない。出生、成長、死亡、移住を分ける。

子どもはまず食料と住居を必要とし、成長後に労働と課税対象の生産へ参加する。人口増加は将来の生産・税基盤を広げる一方、当面の食料・住居・行政・教育の負担を増やす。人口政策では税収の総額と、国が生活・施設・保護へ支出する額を比較する。出生率は歴史の確定式ではなくゲーム用モデルとして調整する。

現実の出生には所得以外の教育・健康・社会条件も関係する。参考資料を中世の出生率へ直接換算しない。[World Bank: fertility, education and economic incentives](https://blogs.worldbank.org/en/health/female-education-and-childbearing-closer-look-data)

## 交通、季節、研究、サービス業

- 道路優先は道への到達・橋・港を含む経路、最短は障害物を避けた距離、手動は合法な経由点の列。道を選ぶ利点は移動時間・積載・安全に分ける。経路がない道路や海への進入は拒否する。
- 海路には船、港または乗降地点、積載、航路、乗船状態が必要。冬季の凍結は海域の通航状態を変える。進行中の船をどこで停止・帰港させるかを定義してから実装する。
- 越境検知は実際の位置、衛兵の視認、集団の協定を使う。同じ検知中に毎フレーム信頼を減らさず、事件単位で集約する。無所属という理由だけで現地に衛兵・権利者がいないとはしない。
- 灌漑は人員・建材・工期と水量を必要とし、水のない土地に無料で農地を作らない。維持作業と季節流量を計算する。
- 蒸気研究は資金・人材・期間・設備を必要とする。研究解禁と各施設への導入費を分ける。有限資源を高速採掘すれば枯渇も早まり、燃料需要も増える。
- 遺跡は調査・発見後に知識や訪問需要へ接続。観光収入は訪問者が実際に支払う資金の移転とし、道路、宿泊、余暇と可処分所得に依存させる。
- 中継貿易の料金は利用された港・道・保管・仲介への対価。流通がない場所に固定の手数料収入を生成しない。酒・ワインは食料・土地・労働を加工業へ配分する選択を作る。

## 更新の順序と完成条件

1. 保存基盤（今回）：時計・人物・命令・国境・履歴の復元。失敗時は現状維持。バックアップ復元。
2. 食料・木材・石材、生活、国庫・個人在庫、現物税、基本の季節・仕事。保存形式を更新し、税・再分配・生産・消費の原因を表示する。
3. 隠れた地質、開拓・調査、有限鉱山、鉄・工具・衣料、所有・利益契約、輸送・基本交易。発見報告と開発費を表示する。
4. 民の求人・家計判断、国家による雇用、待遇、担当者への委任と規則編集。必要な民AIは経済段階から導入し、役職の高度な委任を後続へ拡張する。
5. 金銀貨・市場・銀行・紙幣・為替。税・利息・返済・発行を区別し、元帳を保存する。
6. 部隊・補給・越境検知と事件・海運の安全。外交に保護契約と国籍変更、条約、経済圏を接続する。全面的な国家間戦争はこの基盤の後。
7. 人口の出生と成長、蒸気と工業化、酒類・遺跡・観光・国際制度を、各依存関係が成立した更新で追加する。

海運の基本輸送は第3段階に含め得る。海上戦闘は後段。高度な外交まで基本交易を待たせない。全部を一度に実装せず、各段階を遊べる状態で完成させる。

検証：在庫が負にならない、採掘は埋蔵量を超えない、移転と課税で資源が複製されない、作業担当と他の命令が二重実行されない、停止中の月次処理が進まない、ロードで収穫・税・発見を再実行しない、未知の鉱床が画面から漏れない、契約拒否時は権利と国籍が不変、税率を上げても必ず税収が増えるわけではない。税率・労働配分・待遇・交易条件を変えたケースを比較し、仮数値の有効範囲を記録する。
