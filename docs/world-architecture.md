# v0.2 実装メモ

## 責務と流れ

`scenes/world.tscn` → `world_controller.gd` が1つの `world_state.gd` を所有する。毎フレームの実時間はこの所有者から一度だけ状態へ渡す。UIの描画頻度やカメラの位置はシミュレーションを変えない。

- `geography.gd`：陸地・島・河川・崖・橋・標石。政治的所有権に依存しない不可視の可視性グラフとAStar2Dで経路を返す。
- `border_treaty.gd`：確定国境、編集中の提案、領土ポリゴン、交換面積、仮のNPC判定、合意時の更新。
- `world_state.gd`：人物の所属・所在・命令、移動と巡回、時計、公開命令の検証、記録。画像や画面サイズに依存しない。
- `map_view.gd`：カメラと入力座標変換。クリック・ドラッグをシグナルで通知。世界を直接更新しない。
- `world_map.gd`：仮アートの地形・領域・拠点・人物・選択経路の描画。
- `world_controller.gd`：意図を状態APIへ渡し、結果と理由をUIへ反映する。

人物のID・所属と現在の所在領土は別に保持・計算する。拠点の所属も国境編集で自動変更しない。国家滅亡・軍事占領・人材の心理・経済は後続段階の責務として設計資料に記録している。

## 最小API

| API | 結果 |
| --- | --- |
| `issue_move(id, destination)` / `issue_patrol(id, destination)` / `halt(id)` | `ok` と理由を返す。無効な命令は既存の行動を変更しない |
| `set_paused(value)` / `set_speed(1/2/4)` / `advance(real_seconds)` | 共通の固定刻み時計を制御 |
| `begin_proposal()` / 点の移動・挿入・削除 | 確定国境を保持したまま提案を編集 |
| `submit_proposal()` | 形状と面積の検証、NPCの判定。合意時のみ両国を同時更新 |
| `cancel_proposal()` | 提案だけを破棄 |

`changed` はUIの再評価に使い、移動は共通時計の中で進める。メッセージや表示から行動を再実行しない。初期化ではカメラ以外の状態を新しくし、信号接続も新しい所有者へ付け替える。

## 国境の幾何

固定の両端を持つ北から南への折れ線を、両国が共通の境界として使う。各国の海岸輪郭と境界を合わせたポリゴンで領土を表す。点と線が本土内にあること、北南順、非自己交差、非分断、拠点の維持、ポリゴンの重複・面積保存を確認する。

提案後の自国領から現在の自国領を引いた領域が自国の取得面積。相手国も同様に計算する。Geometry2Dの差集合の符号付き輪郭を使い、穴の向きを面積に反映する。仮の面積単位は地図座標の二乗。

対象は両国の本土境界のみで、無所属の北部と島は交渉に参加しない。軍の占領や海上利権をこの領域へ混同して実装しない。

## 仮数値と技術設定

| 設定 | 値 | 理由 / 扱い |
| --- | --- | --- |
| 人数 | 24 | `[PLACEHOLDER]` 個人操作を小規模で検証 |
| 移動速度 | 50座標単位/秒 | `[PLACEHOLDER]` 経路を目視でき、橋への移動も短時間で確認 |
| NPCの取得/譲渡比 | 0.95以上 | `[PLACEHOLDER]` 面積だけの取引。ほぼ同面積を許容 |
| 拠点と境界の距離 | 40座標単位以上 | `[PLACEHOLDER]` 村・城塞の仮敷地を保護 |
| 標石への吸着 | 18座標単位未満 | `[PLACEHOLDER]` 境界の点を置きやすくする |
| 国境の編集点 | 最大32 | 試作の計算負荷を抑える技術制限 |
| 境界の北南間隔・海岸間隔 | 4座標単位以上 | 接触と縮退で国の領域が分断されるのを防ぐ技術許容幅 |
| シミュレーション刻み | 0.1ゲーム秒 | 速度変更時も同じ移動更新を適用する技術設定 |

無効入力、95%条件の両側、島の非到達、海岸を横切る線などを自動テストする。給与・資源・仕事の生産値は未定なので、この段階では作らない。

## 検証用スクリプト

- `tests/world_smoke.gd`：状態・地理・交換・画面の接続を118項目で確認。
- `tests/world_input.gd`：GodotのルートビューポートへGUI入力を注入して11項目を確認。論理座標を渡すため `push_input(event, true)` を使う。
- `tests/world_preview.gd`：実描画から7枚のPNGを保存。SubViewportのテクスチャも更新された後に取得する。
- `tests/smoke.gd`：変更しない旧版を46項目で確認。

テストはゲームバランスの証明ではない。写実的な地形・交通・経済の本格的モデル、長期の人物数、プレイヤーの理解しやすさは後続の観察と検証で扱う。
